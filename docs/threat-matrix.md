# Security threat matrix

Ratings describe **residual** risk after PRAMAAN's controls: **High** (control mainly detects or
records; an attacker with the stated capability can still succeed), **Medium** (control raises cost
substantially; bypass needs skill or collusion), **Low** (strong technical control; residual only under
unusual conditions). No threat is rated "eliminated". "Review" states what a human must decide.
